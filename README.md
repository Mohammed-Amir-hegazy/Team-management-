# إدارة الشغل — Team Management

نظام لإدارة الشغل داخل الشركة بالأدوار، بواجهة عربية بالكامل.

## الأدوار

```
صاحب الشركة
   └── مدير
         └── تيم ليدر
               └── موظف
```

- كل شخص له **مسؤول مباشر واحد** في المستوى اللي فوقه بالظبط.
- كل شخص بيضيف الناس اللي تحته بس (صاحب الشركة بيضيف مديرين، المدير بيضيف تيم ليدرز وموظفين تحتهم، وهكذا).
- **الريبورتات والطلبات بتتبعت للمسؤول المباشر بس** — السيرفر نفسه بيمنع إن حد يتخطى المستوى اللي فوقه.
  المسؤول يقدر يرد، أو **يحوّل** الريبورت/الطلب للمستوى اللي فوقه (خطوة خطوة من غير تخطي).

## المميزات

| الميزة | التفاصيل |
|---|---|
| المشاريع | كل موظف شايف المشاريع اللي هو عضو فيها. المدير والتيم ليدر بيشوفوا مشاريع فريقهم كمان. |
| التاسكات | جوه كل مشروع. لكل تاسك: مسؤول، أولوية، **ديدلاين**، و**تنبيه (الارم)**. |
| الحالة وسببها | لم تبدأ / قيد التنفيذ / متوقفة / قيد المراجعة / مكتملة — مع **سبب أو ملاحظة** لكل تغيير (إجباري لو "متوقفة")، وسجل كامل بكل التغييرات. |
| الارم | في المعاد المحدد بيظهر تنبيه بصوت + رسالة + إشعار المتصفح. ولما الديدلاين يعدي بيتبعت تنبيه للموظف وللمسؤول عنه. |
| المتطلبات | الموظف بيضيف اللي محتاجه لكل تاسك، وبعدين **بضغطة زرار** يبعت كل طلبات التاسك، أو كل طلبات المشروع مرة واحدة، للمسؤول المباشر. المسؤول يوافق أو يرفض (مع السبب) أو يحوّل لفوق، والرد بيرجع لصاحب الطلب. |
| الريبورتات | ريبورت عام أو عن مشروع/تاسك معين، بيروح للمسؤول المباشر تلقائياً. |
| لوحة التحكم | تاسكاتك حسب الحالة، المتأخر، ديدلاينز الأسبوع، والتاسكات المتوقفة/المتأخرة في فريقك. |

## التشغيل

محتاج **Node.js 22.13 أو أحدث** بس — مفيش أي مكتبات خارجية (قاعدة البيانات SQLite مدمجة في Node).

```bash
npm start
```

افتح `http://localhost:3000` — أول مرة هيطلب منك تعمل حساب صاحب الشركة.

متغيرات اختيارية:

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `3000` | البورت |
| `DB_FILE` | `data/team.db` | مكان ملف قاعدة البيانات |
| `COOKIE_SECURE` | — | خليها `1` لو شغال على HTTPS |

## النشر على الإنترنت (عشان تفتحه من الموبايل)

المشروع جاهز للنشر على [Render](https://render.com) بملف `render.yaml`:

1. اعمل حساب على Render وادخل بحساب GitHub.
2. **New → Blueprint** واختار الريبو ده (والفرع اللي فيه الكود).
3. اضغط **Apply** — هيديك لينك زي `https://team-management-xxxx.onrender.com`.
4. افتح اللينك من الموبايل، واعمل حساب صاحب الشركة **فوراً** (أول حد يفتح اللينك هو اللي بيعمله).
5. من المتصفح: **Add to Home Screen / إضافة للشاشة الرئيسية** — هيبقى زي التطبيق.

الملف بيستخدم خطة Starter مع Disk ثابت عشان البيانات تفضل محفوظة.
الخطة المجانية بتمسح البيانات كل ما السيرفر ينام أو يتعمله إعادة تشغيل، فتنفع للتجربة بس.

ينفع كمان تشغله على أي استضافة بتدعم Docker (Railway, Fly.io, VPS) بالـ `Dockerfile`،
بشرط تربط مجلد `/data` بـ volume ثابت.

## هيكل المشروع

```
server/
  index.js          تشغيل السيرفر + جدولة التنبيهات
  app.js            توجيه الطلبات والتحقق من تسجيل الدخول
  db.js             جداول قاعدة البيانات
  access.js         الأدوار والتسلسل وكل قواعد الصلاحيات
  requirements.js   إرسال الطلبات بضغطة زرار
  scheduler.js      الارم وتنبيهات الديدلاين
  routes/           users, projects, tasks, requests, reports, notifications
public/             الواجهة (HTML/CSS/JS بالعربي)
test/               اختبارات الـ API
```
