# ابتكار — منصة إدارة الأعمال

منصة لإدارة المشاريع والمهام والتقارير داخل الشركة، بتسلسل إداري واضح وواجهة عربية بهوية ابتكار.

## المنصة والاشتراكات (SaaS)

المنصة تخدم عدة شركات في وقت واحد، ولكل شركة مساحة معزولة تمامًا عن غيرها.

| الميزة | التفاصيل |
|---|---|
| لوحة إدارة المنصة | لمالك المنصة: كل الشركات مع **عدّاد تنازلي حيّ** لموعد التجديد، والحسابات المستخدمة، وآخر نشاط، وفلاتر (تجريبي، سنوي، ملكية، ينتهي قريبًا، منتهٍ، موقوف). |
| الاشتراك السنوي | بعدد حسابات محدد؛ لا يمكن تفعيل حسابات أكثر من الباقة. التجديد يُضاف إلى تاريخ الانتهاء الحالي. |
| الفترة التجريبية | أي شركة تسجّل بنفسها من صفحة الدخول تحصل على شهر مجاني (قابل للتمديد من اللوحة). |
| الملكية الدائمة | عند شراء الشركة للنظام بالكامل: ترخيص دائم دون تاريخ انتهاء ودون تذكيرات. |
| تذكير بالتجديد | تلقائيًا قبل الانتهاء بـ 30 و14 و7 و3 ويوم واحد، ثم عند الانتهاء: لصاحب الشركة ومسؤول النظام داخل المنصة (وبالبريد إن كان مفعّلًا)، مع تنبيه لمالك المنصة. ويمكن التذكير يدويًا عبر واتساب. |
| عند الانتهاء أو الإيقاف | يتوقف العمل مؤقتًا وتبقى البيانات محفوظة بالكامل، ويستطيع صاحب الشركة طلب التجديد من صفحة «الاشتراك». |
| التحكم في المستخدمين | من صفحة كل شركة: إيقاف أي حساب أو تفعيله أو حذفه، وإعادة تعيين كلمة المرور، وسجل كامل لأحداث الاشتراك. |
| حذف الحسابات والشركات | كل مستخدم يحذف حسابه من «حسابي» بكلمة المرور: تُمحى بياناته الشخصية ويصبح بريده متاحًا، وتنتقل مهامه المفتوحة وفريقه وطلباته المعلّقة إلى مسؤوله المباشر، وتبقى السجلات باسم «حساب محذوف». صاحب الشركة الوحيد فيها يحذف الشركة بحذف حسابه. ومالك المنصة يحذف أي حساب، أو شركة كاملة بكتابة اسمها للتأكيد. |

- **مالك المنصة دائمًا هو الحساب `mohammedamirwork@gmail.com`** (يمكن تغييره بالمتغير `PLATFORM_OWNER_EMAIL`)، أيًّا كانت البيانات؛ ولا يحصل أي حساب آخر على لوحة إدارة المنصة. وتُحوَّل شركته تلقائيًا إلى ملكية دائمة.
- **التحقق بخطوتين لمالك المنصة**: بعد كلمة المرور يُرسل رمز من 6 أرقام إلى الرقم `01018736900` عبر واتساب أو SMS، أو إلى بريده (المتغير `PLATFORM_OWNER_PHONE`)، ويمكن التبديل بين الطرق وإعادة الإرسال. الرمز صالح 10 دقائق ولخمس محاولات. يلزم تفعيل خدمة إرسال واحدة على الأقل (Brevo أو Twilio)؛ وإلا يدخل بكلمة المرور مع تنبيه.
- **من يسجّل الشركة** قد يكون صاحبها، أو مسؤول النظام فيها؛ ويختار مسؤول النظام معه دوره الوظيفي (مدير أو قائد فريق أو موظف). ويستطيع لاحقًا إضافة حساب صاحب الشركة (حساب واحد فقط) من «الموظفون والحسابات»، فيتبعه تلقائيًا من هم في قمة الهيكل. وإلى أن يُضاف صاحب الشركة يمكن وضع المديرين (أو غيرهم) في قمة الهيكل «بدون مسؤول مباشر».
- **البيانات لا تُحذف مع التحديثات**: كل تعديل على قاعدة البيانات إضافي فقط (جداول وأعمدة جديدة)، ولا يُمسح أي سجل. عند التحديث من نسخة سابقة تُنقل البيانات الحالية تلقائيًا إلى شركة «ابتكار».

## الأدوار والصلاحيات

| الدور | الصلاحيات |
|---|---|
| صاحب الشركة | يرى كل شيء، وينشئ الحسابات ويديرها |
| مسؤول النظام | ينشئ الحسابات ويعدّل الأدوار والمسميات الوظيفية ويوقف الحسابات |
| مدير | ينشئ المشاريع، ويتابع كل ما يخص من هم تحته |
| قائد فريق | ينشئ المشاريع والمهام لفريقه، ويتابع فريقه، ويصدّر تقرير الفريق الشامل |
| موظف | ينفّذ المهام، ويحدّث حالتها، ويرفع التقارير والمتطلبات |

- **إنشاء الحسابات** متاح لصاحب الشركة ومسؤول النظام فقط.
- يمكن أن يحمل الشخص **أكثر من دور** (مثل: قائد فريق + موظف، أو موظف + مسؤول النظام)، ويُحدَّد مستواه في الهيكل بأعلى دور.
- لكل شخص **مسمى وظيفي** حر (مصمم واجهات، محاسب، مطوّر…) يظهر في كل مكان بدل كلمة «موظف».
- **التقارير والطلبات تُرسل إلى المسؤول المباشر فقط**، ويمكنه إحالتها إلى المستوى الأعلى خطوة بخطوة دون تخطٍّ.
- المدير وقائد الفريق وصاحب الشركة يطّلعون على مهام فريقهم وتقاريره وطلباته (اطلاع فقط).

## المميزات

- **الوضع الداكن والفاتح**: زر في أعلى كل صفحة (وفي شاشة الدخول) للتبديل بضغطة، وفي «حسابي» ثلاثة خيارات: تلقائي (حسب إعداد الجهاز) أو فاتح أو داكن، ويُحفظ الاختيار على الجهاز. التقارير المطبوعة (PDF) تخرج دائمًا بالوضع الفاتح.

| الميزة | التفاصيل |
|---|---|
| المشاريع والمهام | لكل مهمة مسؤول وأولوية وموعد نهائي وتنبيه. |
| حالة المهمة وسببها | لم تبدأ / قيد التنفيذ / متوقفة / قيد المراجعة / مكتملة، مع سبب لكل تغيير (إلزامي عند التوقف) وسجل كامل. |
| التنبيهات | تنبيه بصوت ورسالة في الموعد المحدد، وتنبيه للموظف ومسؤوله عند تجاوز الموعد النهائي. |
| المتطلبات | تُضاف لكل مهمة، وتُرسل **بضغطة زر** لمهمة واحدة أو للمشروع كاملًا، مع موافقة أو رفض أو إحالة. |
| التقارير | يُرفق بكل تقرير تلقائيًا **حالة العمل كاملة**: المهام وحالاتها وأسباب التوقف والمواعيد، وملخص الفريق لمن لديه فريق. |
| متابعة الفريق | لوحة لكل عضو، والمهام المتوقفة والمتأخرة، وتقارير الفترة، مع **تنزيل تقرير الفريق الشامل في ملف واحد (PDF أو Excel) بضغطة زر**. |
| استعادة كلمة المرور | «نسيت كلمة المرور؟» يرسل رمز تحقق من 6 أرقام إلى البريد الإلكتروني أو واتساب أو رسالة نصية، صالحًا لعشر دقائق وبخمس محاولات كحد أقصى. |
| صور داعمة للتنفيذ | يرفع عضو الفريق صورًا لكل مهمة (تُخزَّن على Cloudinary)، وتُرفق تلقائيًا بتقاريره، ويمكن إرفاق صور بالتقرير مباشرة. |
| التقرير الاحترافي | يُعرض التقرير بوصفه مستندًا بهوية ابتكار، مع تنزيله PDF، وإرساله عبر واتساب إلى المسؤول المباشر أو أي مستوى أعلى برسالة منسّقة. |
| أرقام واتساب والتذكير | لكل مستخدم رقم واتساب. زر «تذكير» عند كل شخص: للمسؤول بطلب معلّق، وللموظف بمهمة عليه، أو رسالة عامة، وتُصاغ الرسالة رسميًا للأعلى وزمالةً للأدنى، مع تنبيه داخل المنصة. |
| المهام المستقلة | يضيف كل موظف مهامًا لنفسه داخل مشروع أو «بدون مشروع»، ويطّلع عليها مسؤولوه. |
| مشاريع الموظفين | يستطيع أي موظف إنشاء مشروع خاص به وإضافة مهامه فيه، ويتابعه مسؤولوه في السلسلة. |
| الواجهة | هوية ابتكار (الشعار والألوان والخط)، شريط تنقل سفلي على الجوال، وضع داكن تلقائي، وحركات هادئة تحترم إعداد «تقليل الحركة». |

> **ملاحظة عن الخط:** خط DIN Next LT Arabic المضمَّن في `public/fonts` خط تجاري من Linotype؛ يُرجى التأكد من امتلاك ترخيص استخدامه على الويب.

## التشغيل على جهازك

محتاج **Node.js 20 أو أحدث**.

```bash
npm install
npm start
```

افتح `http://localhost:3000` — أول مرة هيطلب منك تعمل حساب صاحب الشركة.
لو مفيش إعدادات Turso، البيانات بتتحفظ في ملف محلي `data/team.db`.

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `3000` | البورت |
| `TURSO_DATABASE_URL` | — | رابط قاعدة بيانات Turso (`libsql://....turso.io`) |
| `TURSO_AUTH_TOKEN` | — | توكن Turso |
| `DB_FILE` | `data/team.db` | ملف قاعدة البيانات المحلي (لو مفيش Turso) |
| `COOKIE_SECURE` | — | خليها `1` لو شغال على HTTPS |

## النشر مجاناً بالكامل (Render + Turso)

البيانات بتتحفظ على **Turso** (مجاني)، والموقع شغال على **Render** (مجاني).

### 1) قاعدة البيانات على Turso
1. ادخل [app.turso.tech](https://app.turso.tech) واعمل حساب (ينفع بحساب GitHub).
2. **Create Database** — اختار اسم (مثلاً `team-management`) وأقرب منطقة ليك.
3. من صفحة قاعدة البيانات انسخ الـ **URL** (بيبدأ بـ `libsql://`).
4. اضغط **Create Token** (صلاحية Read & Write، ومن غير تاريخ انتهاء) وانسخ التوكن.

### 2) الموقع على Render
1. ادخل [render.com](https://render.com) واعمل حساب بحساب GitHub.
2. **New → Blueprint** واختار الريبو ده والفرع اللي فيه الكود.
3. هيطلب منك قيمتين: حط الـ URL في `TURSO_DATABASE_URL` والتوكن في `TURSO_AUTH_TOKEN`.
4. **Apply** — بعد ما يخلص هيديك لينك زي `https://team-management-xxxx.onrender.com`.
5. افتح اللينك من الموبايل واعمل حساب صاحب الشركة **فوراً**، وبعدين من المتصفح: **إضافة للشاشة الرئيسية**.

### 3) خدمات اختيارية (تُضاف من تبويب Environment في Render)

| الخدمة | المتغيرات | ملاحظات |
|---|---|---|
| رفع الصور — [Cloudinary](https://cloudinary.com) (مجاني) | `CLOUDINARY_URL` | تجده في لوحة Cloudinary بصيغة `cloudinary://API_KEY:API_SECRET@CLOUD_NAME` |
| رمز التحقق بالبريد — [Brevo](https://www.brevo.com) (300 رسالة يوميًا مجانًا) | `BREVO_API_KEY` و`MAIL_FROM` | يجب توثيق بريد المرسل في Brevo. بديل: `RESEND_API_KEY` من Resend |
| رمز التحقق بواتساب أو SMS — [Twilio](https://www.twilio.com) (مدفوع) | `TWILIO_ACCOUNT_SID` و`TWILIO_AUTH_TOKEN` و`TWILIO_WHATSAPP_FROM` و/أو `TWILIO_SMS_FROM` | يتطلب واتساب في الإنتاج قالب رسالة معتمدًا من Twilio |
| رمز الدولة الافتراضي | `DEFAULT_COUNTRY_CODE` (الافتراضي `20`) | لتحويل الأرقام المحلية مثل 010… إلى الصيغة الدولية |
| رقم واتساب المنصة | `PLATFORM_CONTACT_PHONE` | الرقم الذي تتواصل عليه الشركات لطلب التجديد |
| مالك المنصة | `PLATFORM_OWNER_EMAIL` و`PLATFORM_OWNER_PHONE` | الافتراضي `mohammedamirwork@gmail.com` و`201018736900`؛ إليه تُرسل رموز الدخول |
| الفترة التجريبية | `TRIAL_DAYS` (30) و`TRIAL_SEATS` (10) | مدة التجربة وعدد حساباتها؛ `ALLOW_SIGNUP=0` يوقف التسجيل الذاتي |

تظهر خيارات «نسيت كلمة المرور» وزر رفع الصور تلقائيًا بحسب الخدمات المفعّلة.
أزرار واتساب للتقارير والتذكير لا تحتاج أي إعداد؛ فهي تفتح تطبيق واتساب برسالة جاهزة.

### ⚠️ لماذا قد تختفي البيانات بعد التحديث؟
إذا لم يُضبط `TURSO_DATABASE_URL` على Render، تُحفظ قاعدة البيانات في ملف على قرص الخادم المؤقت، و**Render يمحو هذا القرص مع كل نشر أو إعادة تشغيل**؛ فيبدو كأن البيانات حُذفت. الحل: اضبط `TURSO_DATABASE_URL` و`TURSO_AUTH_TOKEN` (الخطوة 1 أعلاه). ويظهر تحذير أحمر في لوحة إدارة المنصة وفي سجل الخادم طالما التخزين مؤقت.

### ملاحظة مهمة عن الخطة المجانية
السيرفر المجاني على Render **بينام بعد 15 دقيقة من غير استخدام**، وأول فتحة بعدها بتاخد حوالي دقيقة.
البيانات مش بتضيع (محفوظة على Turso)، بس **التنبيهات (الارم) مش بتتبعت وهو نايم** —
بتتبعت أول ما يصحى. عشان يفضل صاحي على طول ببلاش:
اعمل حساب على [cron-job.org](https://cron-job.org) وخليه يفتح `https://<اللينك بتاعك>/api/health` كل 10 دقايق.
