# ابتكار — منصة إدارة الأعمال

منصة لإدارة المشاريع والمهام والتقارير داخل الشركة، بتسلسل إداري واضح وواجهة عربية بهوية ابتكار.

## الأدوار والصلاحيات

| الدور | الصلاحيات |
|---|---|
| صاحب الشركة | يرى كل شيء، وينشئ الحسابات ويديرها |
| مسؤول النظام | ينشئ الحسابات ويعدّل الأدوار والمسميات الوظيفية ويوقف الحسابات |
| مدير | ينشئ المشاريع، ويتابع كل ما يخص من هم تحته |
| قائد فريق | ينشئ المشاريع والمهام لفريقه، ويتابع فريقه، ويصدّر تقرير الفريق الشامل |
| موظف | ينفّذ المهام، ويحدّث حالتها، ويرفع التقارير والمتطلبات |

- **إنشاء الحسابات** متاح لصاحب الشركة ومسؤول النظام فقط.
- يمكن أن يحمل الشخص **أكثر من دور** (مثل: قائد فريق + موظف، أو موظف + مسؤول النظام)، ويُحدَّد مستواه في الهيكل بأعلى دور.
- لكل شخص **مسمى وظيفي** حر (مصمم واجهات، محاسب، مطوّر…) يظهر في كل مكان بدل كلمة «موظف».
- **التقارير والطلبات تُرسل إلى المسؤول المباشر فقط**، ويمكنه إحالتها إلى المستوى الأعلى خطوة بخطوة دون تخطٍّ.
- المدير وقائد الفريق وصاحب الشركة يطّلعون على مهام فريقهم وتقاريره وطلباته (اطلاع فقط).

## المميزات

| الميزة | التفاصيل |
|---|---|
| المشاريع والمهام | لكل مهمة مسؤول وأولوية وموعد نهائي وتنبيه. |
| حالة المهمة وسببها | لم تبدأ / قيد التنفيذ / متوقفة / قيد المراجعة / مكتملة، مع سبب لكل تغيير (إلزامي عند التوقف) وسجل كامل. |
| التنبيهات | تنبيه بصوت ورسالة في الموعد المحدد، وتنبيه للموظف ومسؤوله عند تجاوز الموعد النهائي. |
| المتطلبات | تُضاف لكل مهمة، وتُرسل **بضغطة زر** لمهمة واحدة أو للمشروع كاملًا، مع موافقة أو رفض أو إحالة. |
| التقارير | يُرفق بكل تقرير تلقائيًا **حالة العمل كاملة**: المهام وحالاتها وأسباب التوقف والمواعيد، وملخص الفريق لمن لديه فريق. |
| متابعة الفريق | لوحة لكل عضو، والمهام المتوقفة والمتأخرة، وتقارير الفترة، مع **تنزيل تقرير الفريق الشامل في ملف واحد (PDF أو Excel) بضغطة زر**. |
| الواجهة | هوية ابتكار (الشعار والألوان والخط)، شريط تنقل سفلي على الجوال، وضع داكن تلقائي، وحركات هادئة تحترم إعداد «تقليل الحركة». |

## التشغيل على جهازك

محتاج **Node.js 20 أو أحدث**.

```bash
npm install
npm start
```

افتح `http://localhost:3000` — أول مرة هيطلب منك تعمل حساب صاحب الشركة.
لو مفيش إعدادات Turso، البيانات بتتحفظ في ملف محلي `data/team.db`.

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `3000` | البورت |
| `TURSO_DATABASE_URL` | — | رابط قاعدة بيانات Turso (`libsql://....turso.io`) |
| `TURSO_AUTH_TOKEN` | — | توكن Turso |
| `DB_FILE` | `data/team.db` | ملف قاعدة البيانات المحلي (لو مفيش Turso) |
| `COOKIE_SECURE` | — | خليها `1` لو شغال على HTTPS |

## النشر مجاناً بالكامل (Render + Turso)

البيانات بتتحفظ على **Turso** (مجاني)، والموقع شغال على **Render** (مجاني).

### 1) قاعدة البيانات على Turso
1. ادخل [app.turso.tech](https://app.turso.tech) واعمل حساب (ينفع بحساب GitHub).
2. **Create Database** — اختار اسم (مثلاً `team-management`) وأقرب منطقة ليك.
3. من صفحة قاعدة البيانات انسخ الـ **URL** (بيبدأ بـ `libsql://`).
4. اضغط **Create Token** (صلاحية Read & Write، ومن غير تاريخ انتهاء) وانسخ التوكن.

### 2) الموقع على Render
1. ادخل [render.com](https://render.com) واعمل حساب بحساب GitHub.
2. **New → Blueprint** واختار الريبو ده والفرع اللي فيه الكود.
3. هيطلب منك قيمتين: حط الـ URL في `TURSO_DATABASE_URL` والتوكن في `TURSO_AUTH_TOKEN`.
4. **Apply** — بعد ما يخلص هيديك لينك زي `https://team-management-xxxx.onrender.com`.
5. افتح اللينك من الموبايل واعمل حساب صاحب الشركة **فوراً**، وبعدين من المتصفح: **إضافة للشاشة الرئيسية**.

### ملاحظة مهمة عن الخطة المجانية
السيرفر المجاني على Render **بينام بعد 15 دقيقة من غير استخدام**، وأول فتحة بعدها بتاخد حوالي دقيقة.
البيانات مش بتضيع (محفوظة على Turso)، بس **التنبيهات (الارم) مش بتتبعت وهو نايم** —
بتتبعت أول ما يصحى. عشان يفضل صاحي على طول ببلاش:
اعمل حساب على [cron-job.org](https://cron-job.org) وخليه يفتح `https://<اللينك بتاعك>/api/health` كل 10 دقايق.
